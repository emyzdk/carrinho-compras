# 🛒 Carrinho de Compras

## 🧩 Sobre o Projeto
O "Carrinho de Compras" é uma aplicação front-end desenvolvida para simular a funcionalidade essencial de um e-commerce. Este projeto foi criado como parte dos exercícios propostos nos cursos de desenvolvimento web da Alura, focando na integração fluida entre as tecnologias front-end. O objetivo principal da aplicação é praticar a manipulação do DOM e a lógica de cálculo em tempo real utilizando JavaScript, permitindo ao usuário gerenciar itens no carrinho e visualizar o total da compra dinamicamente.
